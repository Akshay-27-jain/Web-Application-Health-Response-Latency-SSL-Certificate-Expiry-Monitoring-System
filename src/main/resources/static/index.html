Frequently Asked Questions

Technical details about our synthetic probes, database, and notifications.

How does the SSL certificate expiration check work?
During synthetic health checks, our probe initiates a non-blocking TLS handshake, inspects the X.509 certificate expiry date, and computes remaining validity days. If expiry is within 30 days, alerts trigger automatically.
What database is used for storing logs and monitors?
The platform is powered by an enterprise-grade PostgreSQL 18 database with Spring Data JPA. All monitors, users, ping logs, and notification webhooks are permanently stored with zero data loss.
Can I monitor private internal backend ports?
Yes! You can monitor any TCP socket port (such as PostgreSQL 5432, Redis 6379, MySQL 3306, or DNS 53) simply by choosing "TCP Port Probe" when creating a new target.
