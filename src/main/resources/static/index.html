Frequently Asked Questions

Common questions about our synthetic probes, alerts, and database architecture.

How does the SSL certificate expiry tracking work?
During every synthetic health check, our probe initiates a lightweight TLS handshake, extracts the X.509 certificate expiry date, and calculates remaining validity days. If expiry is within 30 days, alerts are triggered automatically.
What database does UptimePulse use for persistence?
UptimePulse operates on an enterprise-grade PostgreSQL 18 database with Spring Data JPA. All monitors, users, ping logs, and notification webhooks are permanently stored with zero data loss.
Can I monitor raw TCP backend ports in addition to HTTP?
Yes! You can monitor any TCP service (such as Redis 6379, PostgreSQL 5432, MySQL 3306, or DNS 53) simply by selecting "TCP Port Probe" when adding a new monitor.
