Frequently Asked Questions

Common questions about our probes, SSL tracking, and alert integrations.

How does the SSL certificate expiration check work?
During each health check, our probe initiates a lightweight TLS handshake, extracts the X.509 certificate expiry date, and calculates remaining validity days. If expiry is within 30 days, alerts trigger automatically.
Can I monitor raw TCP backend ports?
Yes! You can monitor any TCP socket port (such as PostgreSQL 5432, Redis 6379, MySQL 3306, or DNS 53) simply by selecting "TCP Port Probe" when adding a new target.
Which notification channels are supported?
UptimePulse supports Slack incoming webhooks (Block Kit), Discord channel webhooks, transactional HTML emails, and custom HTTP POST JSON webhooks.
