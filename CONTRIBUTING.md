# Contributing to Web Application Health & SSL Monitoring System

Thank you for considering contributing to this project!

## Getting Started
1. Fork the repository on GitHub.
2. Clone your fork locally: `git clone https://github.com/your-username/Web-Application-Health-Response-Latency-SSL-Certificate-Expiry-Monitoring-System.git`
3. Create a feature branch: `git checkout -b feature/my-new-feature`
4. Run tests and verify build cleanliness: `mvn test`

## Code Guidelines
- Ensure Java 21 features (Virtual Threads, Records) follow clean code principles.
- Maintain RESTful API standards and OpenAPI documentation annotations.
- Include appropriate unit tests for any new features or bug fixes.
