# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please do NOT create a public issue.

Instead, please send an email to the maintainers or submit a private security disclosure on GitHub.

### Vulnerability Report Process:
1. Provide a detailed summary of the vulnerability.
2. Include steps or proof-of-concept code to reproduce the issue.
3. The maintainers will acknowledge receipt within 48 hours and provide updates on resolution.
